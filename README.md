# Tasador de inmuebles — demo

App de escritorio (Electron) que arma la tasación completa de un inmueble —catastro, fotos y memoria— y entrega el documento Word listo para firmar.

Capturas de uso del proyecto (repo de código fuente privado). Datos ficticios por protección de datos.
